尚未登入或尚未設定 Firebase

修正版預設改用「跳轉模式」登入，手機 Safari / Chrome 比較穩。若跳轉後回到本頁，系統會自動接續登入狀態並執行智慧同步。

登入後會自動執行：讀取本機與雲端 → 逐筆比較 updatedAt/deletedAt → 合併 → 寫回本機與雲端。同步前會自動保存一份本機備份。

Firebase 登入檢查

如果 Google 登入頁無法開啟，請先確認 Firebase Console 這幾項：

  1. Authentication → Sign-in method → Google 已啟用。
  2. Authentication → Settings → Authorized domains 已加入目前網站網域，例如 GitHub Pages 的 你的帳號.github.io。
  3. 使用 Safari 或 Chrome 直接開啟網站，不要在 GitHub App / LINE / Facebook 內建瀏覽器中登入。
目前網站網域： 若你是 GitHub Pages，Authorized domains 通常要加入： 你的帳號.github.io 你的 Firebase authDomain，例如：你的專案.firebaseapp.com

Firebase 設定方式

請在 HTML 最下方找到 firebaseConfig，把 YOUR_API_KEY 等欄位換成 Firebase 專案提供的設定，並在 Firebase Console 啟用 Authentication 的 Google 登入與 Firestore Database。

Firestore Rules 建議： rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { match /financeUsers/{userId}/data/main { allow read, write: if request.auth != null && request.auth.uid == userId; } } }
